# Linux binaries

`busybox` is the unmodified `/bin/busybox` from Debian's
`busybox-static_1.35.0-4+deb12u1+b1_amd64.deb` (static glibc build).
BusyBox is GPL-2.0; its source is at https://busybox.net and in Debian's
`busybox` source package. It is seeded as `/bin/busybox` and runs under the
Linux personality.
